## 变更

新增独立第三方工具页面，Herdr 默认关闭；检查、确认配置和通知启用分别操作。仅使用用户选择的已启用渠道，开启前确认重复通知风险。沿用现有 UI 组件及配色，保留社区作者链接；五种 README、两种 UI 语言和版本元数据已更新。

普通 hooks status 和 watch 提醒不运行 Herdr。只有显式目标查询执行有超时限制的检测；损坏或旧路径桥接不能显示为已就绪。配置保留自定义字段，正确引用空格、单引号和 shell 元字符路径。桥接固定调用当前运行时，避免依赖全局 Node，并退出 Tauri 专用 stdout 通知模式。
